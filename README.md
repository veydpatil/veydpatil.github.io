# Veyd Patil Portfolio

This portfolio is set up for `https://veydpatil.github.io` and publishes through GitHub Pages when changes are pushed to the `main` branch.

## Update workflow

1. Replace project copy in `app/page.tsx` and `app/projects/quadruped/page.tsx`.
2. Put project photos, renders, and videos in `public/projects/`.
3. Commit and push to GitHub. The deployment workflow publishes the update automatically.

## First GitHub Pages deployment

Create a GitHub repository named `veydpatil.github.io`, push this folder to its `main` branch, then set **Settings > Pages > Build and deployment > Source** to **GitHub Actions**.
